# 研究路线图

本路线图面向“面向人机共适应的个体化主动人体响应世界模型与移动机器人闭环决策”，各阶段以上一阶段的可复现实验结果为基础逐步推进。

## Phase 1：运行环境和统一数据格式（已完成）

- **Phase 1A 状态**：工程骨架已完成。
- **Phase 1B 状态**：WSL2 + PyTorch + RTX 4070 GPU 验证已完成。

- **目标**：建立可复现的工程骨架、环境检查流程和代码—数据分离的数据约定。
- **输入**：现有软硬件环境、ROS 采集数据目录约定、项目需求。
- **输出**：项目目录、路径配置、环境检查脚本、统一数据格式规范和基础测试。
- **主要实验**：验证配置加载、路径解析、依赖探测和最小测试流程；抽样验证数据字段与时间戳约定（不改动原始数据）。
- **进入下一阶段的验收条件**：工程检查与单元测试通过；训练、验证、测试划分规则明确；统一格式能够表达轨迹、时间戳、主体标识和场景元数据。

## Phase 2：人体轨迹预测基线（进行中）

- **当前状态**：Phase 2 已开始，首先建立合成二维轨迹上的 GPU 基线。

- **目标**：建立可复现的二维/平面人体轨迹预测基线与评价协议。
- **输入**：统一格式的人体历史轨迹、机器人状态和场景元数据。
- **输出**：确定性与概率性轨迹预测基线、训练配置、模型权重和评价报告。
- **主要实验**：常速度、循环网络或 Transformer 基线；不同观测/预测时长、跨场景泛化和消融实验。
- **进入下一阶段的验收条件**：基线结果可复现；ADE、FDE 等指标和数据划分固定；模型明显优于简单运动学基线。

## Phase 3：3D人体骨架预测

- **目标**：从质心轨迹扩展到时序一致的 3D 人体姿态与骨架预测。
- **输入**：历史 3D 关节点、人体轨迹、可选 RGB 关键帧和机器人状态。
- **输出**：3D 骨架预测模型、关节点置信度、可视化与误差报告。
- **主要实验**：MPJPE、速度/加速度误差、遮挡鲁棒性、不同骨架拓扑和多模态输入消融。
- **进入下一阶段的验收条件**：预测满足关节结构与时间连续性约束；核心指标优于静态姿态和简单外推基线；失败模式可解释。

## Phase 4：动作条件世界模型

- **目标**：建模机器人动作对未来人体轨迹、姿态及交互状态的条件影响。
- **输入**：人体历史状态、场景上下文、机器人状态和候选动作序列。
- **输出**：动作条件状态转移模型、不确定性估计和多步滚动预测接口。
- **主要实验**：开环多步预测、反事实动作比较、校准度、动作敏感性和分布外测试。
- **进入下一阶段的验收条件**：模型能区分不同机器人动作导致的响应；多步误差与不确定性可控；接口可供规划器批量查询。

## Phase 5：3B多模态基础模型

- **目标**：构建约 3B 参数规模的多模态交互基础模型，统一理解视觉、骨架、轨迹、动作与文本语义。
- **输入**：多模态时序数据、动作条件样本、交互描述及前序阶段监督信号。
- **输出**：多模态表示、预训练/微调方案、下游预测接口和系统化评测。
- **主要实验**：模态对齐、缺失模态鲁棒性、参数高效微调、迁移学习和规模消融。
- **进入下一阶段的验收条件**：在关键预测与理解任务上稳定超过专用基线；资源成本可接受；数据、训练和评估流程可复现。

## Phase 6：个体化分层记忆

- **目标**：通过短期、情景和长期记忆适应不同个体并保持隐私与稳定性。
- **输入**：基础模型表示、个体跨会话交互历史、反馈和上下文。
- **输出**：分层记忆模块、检索/更新策略、个体化预测和遗忘机制。
- **主要实验**：冷启动、少样本适应、跨日保持、灾难性遗忘、隐私边界与个体差异分析。
- **进入下一阶段的验收条件**：个体化相对群体模型有统计显著收益；跨日性能稳定；记忆写入、读取和删除可审计。

## Phase 7：主动微干预与信息增益

- **目标**：选择安全、低打扰的机器人微动作，以信息增益促进个体模型快速适应。
- **输入**：个体化世界模型、不确定性、候选微干预动作和安全约束。
- **输出**：信息增益估计器、主动动作策略、安全过滤器和离线决策评测。
- **主要实验**：被动与主动采样对比、信息增益校准、舒适度/打扰度权衡、安全约束消融。
- **进入下一阶段的验收条件**：在相同交互预算下提升预测或适应效率；无安全约束违规；用户负担在预设阈值内。

## Phase 8：真车闭环与跨日共适应

- **目标**：在真实移动机器人上实现感知—预测—决策—执行闭环，并验证人与机器人的跨日共适应。
- **输入**：在线多模态观测、个体化记忆、主动策略、机器人控制与安全接口。
- **输出**：实时闭环系统、跨日实验数据、系统评估和部署规范。
- **主要实验**：仿真到真机迁移、闭环时延、安全停车、长期用户研究、跨日性能和共适应动力学分析。
- **进入下一阶段的验收条件**：闭环频率、时延和安全指标达到部署要求；跨日研究显示稳定收益；实验可复现并具备完整故障处置方案。
